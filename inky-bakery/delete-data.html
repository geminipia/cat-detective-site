계정·데이터 삭제 안내 — 먹물 탐정의 베이커리 클리커

먹물 탐정의 베이커리 클리커에서 구글 계정을 연결해 클라우드에 저장한 경우, 아래 방법으로 계정 정보와 저장 데이터를 삭제할 수 있습니다.

방법 1. 앱에서 직접 삭제 (가장 빠름)

  1. 앱을 열고 하단의 설정 탭을 엽니다.
  2. 계정(구글) 카드에서 계정·클라우드 데이터 삭제를 누릅니다.
  3. 확인 창에서 삭제를 누르면 클라우드에 저장된 진행 상황과 구글 연결 계정 정보가 즉시 삭제됩니다. 삭제 후에는 되돌릴 수 없습니다.

방법 2. 이메일로 요청 (앱을 지웠거나 기기가 없는 경우)

strophicgames@gmail.com으로 구글 계정 이메일 주소와 앱 이름(먹물 탐정의 베이커리 클리커)을 적어 보내 주세요. 본인 확인 후 영업일 기준 7일 이내에 삭제하고 회신합니다.

삭제되는 정보

정보처리
구글 계정 이메일, 표시 이름, 계정 고유 ID(Firebase Authentication)삭제
클라우드에 저장된 게임 진행 기록과 설정(Cloud Firestore)삭제
이 기기에 저장된 게임 데이터앱 삭제 또는 앱 데이터 삭제로 제거 (클라우드 삭제와는 별개)
